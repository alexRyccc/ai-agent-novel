# SkillForge 交付说明（邮件正文素材草稿）

> 面向非开发背景的收件人。下面每一节都可单独节选进邮件；「【】」内是需要你按实际情况替换的占位。

---

## 这是什么（一句话）

SkillForge 是一个**本地技能管家**：把团队积累的开发规范（比如「怎么写 Spring Boot 接口」「怎么写单元测试」）整理成一份份「技能」，当 AI 助手（Metis）接到任务时，自动选出最对口的那个技能并照着做，做完还能用「真实采纳率」看出哪些技能真的好用、哪些没人用。

## 它解决了什么问题

以前团队规范散落在文档、Wiki、老同事脑子里，Metis 既看不到、也用不上。现在把这些规范落到本机一份份 `SKILL.md` 里，SkillForge 负责三件事：**把技能收进来、在正确时机调对技能、用数据衡量技能好坏**。

## 装起来多简单（一行命令）

前提只有一条：机器上有 **Python 3.11 或更高版本**（不需要联网、不需要装任何第三方包）。

拿到一个单文件 `sfx.pyz` 后，运行：

```
python dist/sfx.pyz serve
```

浏览器打开 **http://127.0.0.1:7788**，就能看到一个本地看板：左边是技能列表，中间能试玩匹配，右边是统计。没有服务器、没有账号、数据都留在你自己机器上。

## 怎么试用（三步）

1. **扫描**：`python dist/sfx.pyz scan --roots demo-skills` —— 把示例技能收进来。
2. **试匹配**：`python dist/sfx.pyz match "帮我写一个 Spring Boot REST 接口"` —— 看它能不能选出对的那个技能。
3. **上报采纳**：某次真的用某个技能干成了活，就 `python dist/sfx.pyz load <技能名>` —— 这是给技能「投一票」，看板上的采纳率才有意义。

## 注意事项

- **内网可用**：整个工具只在本地运行，不连外网，页面断网也能开。
- **数据只在本机**：技能数据、统计都存在本机（Windows 在 `%LOCALAPPDATA%\sfx`），不经过任何服务器。
- **需要 Python 3.11+**：机器上没有的话，先从内网共享盘或 python.org 装一个（勾选「Add to PATH」）。
- **默认只服务本机**：看板默认只监听 127.0.0.1，别人访问不到，安全起见这是刻意的。
- **当前是单机版**：本版本是给个人/小范围验证用的单机工具，不含团队账号、审核等功能（那些是下一阶段的事）。

## 遇到问题

- 端口被占用：换一个端口 `python dist/sfx.pyz serve --port 7789`。
- 不知道数据在哪：`python dist/sfx.pyz doctor` 会打印所有落盘位置。
- 想卸载：删掉数据目录即可（`doctor` 里会告诉你具体路径）。
