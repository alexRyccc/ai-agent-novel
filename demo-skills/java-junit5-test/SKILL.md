# JUnit 5 单元测试

## 目标

产出可重复运行、不依赖外部环境、覆盖正常与边界路径的测试。

## 适用场景

- 为新逻辑补测试
- 遗留代码补测试网
- 重构前的安全网

## 工作流

1. 测试命名遵循 `方法_场景_期望`，读名字即知意图。
2. 用 `@ParameterizedTest` 覆盖等价类与边界值，避免复制粘贴。
3. 外部依赖（DB / HTTP / 时间）一律 mock 或注入可控实现。
4. 一个测试只断言一个行为，避免“大杂烩断言”。
5. 异常断言用 `assertThrows` 并校验异常消息关键片段。

## 检查清单

- [ ] 测试是否可在任意顺序、任意次数重复通过
- [ ] 是否有对当前时间的硬编码依赖（应注入 Clock）
- [ ] 断言是否具体（避免只 assertNotNull）
- [ ] 边界值（null / 空集合 / 极值 / 越界）是否覆盖
- [ ] 测试是否真的会在实现出错时失败（做过反向验证）

## 产出要求

交付：测试类 + 覆盖率报告 + 至少 1 个做过“故意改错验证”的说明。
