# 响应式布局

## 目标

产出在手机/平板/桌面都自然可用的布局，内容不溢出、不重叠。

## 适用场景

- 多端适配
- 移动端体验差
- 窄屏内容溢出

## 工作流

1. 移动优先：先写小屏样式，再用 `min-width` 逐步增强。
2. 布局优先用 Flexbox/Grid + `fr`/`minmax`，减少固定像素宽度。
3. 容器用 `max-width` + 水平内边距，而非百分比硬撑。
4. 断点选在内容开始难读的位置（常见 640 / 900 / 1200），不在设备型号上。
5. 表格/长文本用 `overflow-wrap`、横向滚动容器或卡片化降级。
6. 字号与间距用 `rem`/`clamp()` 支持用户缩放与流式变化。

## 检查清单

- [ ] 是否在 320px 宽下不横向溢出
- [ ] 是否有绝对定位导致的元素重叠
- [ ] 触控目标是否足够大（≥44px）
- [ ] 是否用了 `100vh` 导致移动端地址栏遮挡（应改 `100dvh` 或 `min-height`）
- [ ] 图片/图表是否自适应不撑破容器

## 产出要求

交付：响应式样式 + 三档视口截图（320 / 768 / 1440）+ 溢出检查结论。
