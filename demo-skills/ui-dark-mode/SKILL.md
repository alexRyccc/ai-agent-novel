# 深色模式设计

## 目标

产出色阶合理、对比达标、层次分明的深色主题。

## 适用场景

- 新增深色主题
- 深色下文字发灰/刺眼
- 主题切换

## 工作流

1. 深色不用纯黑（#000），用近黑中性色（如 #0d1117）降低眩光。
2. 层次靠**明度**区分而非纯靠边框：底色越浅表示层级越高。
3. 正文颜色不用纯白（#fff），用略暗的白（如 #e6edf3）降低刺眼感。
4. 彩色（强调色）在深底上需降低饱和度或提亮，保证对比 ≥4.5:1。
5. 阴影在深色下几乎无效，改用边框或更亮的底色表达层级。
6. 用 `prefers-color-scheme` 自动适配，并提供手动切换且记忆选择。

## 检查清单

- [ ] 是否用纯黑底 + 纯白字（对比过强易疲劳）
- [ ] 强调色在深底上对比是否达标
- [ ] 切换主题时是否有元素漏改（硬编码色值）
- [ ] 深色下图片/图标是否需要反色处理
- [ ] 是否尊重了系统主题偏好

## 产出要求

交付：深色令牌定义 + 对比度实测 + 切换实现 + 漏改检查结论。
