# 表单交互体验

## 目标

产出校验及时、错误明确、防重复提交的表单体验。

## 适用场景

- 表单难填
- 错误提示不清晰
- 重复提交

## 工作流

1. 标签置于输入框上方（移动端友好），`for` 正确关联。
2. 校验时机：失焦时校验格式，提交时校验必填，输入时不打断。
3. 错误提示就近显示在字段下方，说明**怎么改**而非只说“格式错误”。
4. 提交中禁用按钮并显示进度，防重复提交；超时可重试且保留已填内容。
5. 必填项有明确标记，可选字段说明是否必填。
6. 输入类型用对（`type="email"`、`inputmode="numeric"`）以调起正确键盘。
7. 离开有未保存内容时提示。

## 检查清单

- [ ] 错误提示是否指向具体字段且说明修复方式
- [ ] 是否防止了重复提交
- [ ] 提交失败后已填内容是否保留
- [ ] 必填标记是否清晰且非仅靠颜色
- [ ] 是否避免了在用户输入过程中报错
- [ ] 移动端键盘类型是否合适

## 产出要求

交付：表单结构 + 校验规则 + 各错误态示例 + 提交状态处理。
