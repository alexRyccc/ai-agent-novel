# 密钥与敏感信息泄露检测

## 目标

检出代码/配置/历史提交中的敏感信息并给出轮换方案。

## 适用场景

- 提交前检查
- 泄露应急
- 配置治理

## 工作流

1. 扫描工作区与 Git 历史（历史提交同样要查，删文件不等于删历史）。
2. 检测范围：AK/SK、数据库密码、JWT 密钥、私钥文件、内网地址。
3. 命中后先判定是否有效（可能已是废弃凭证），再决定优先级。
4. 有效凭证必须**立即轮换**，仅删除代码无效。
5. 改为从环境变量/配置中心注入，并加提交前钩子拦截。

## 检查清单

- [ ] 是否只扫了当前文件没扫 Git 历史
- [ ] 泄露的凭证是否已轮换（这是最关键一步）
- [ ] 是否配置了 pre-commit 钩子
- [ ] 日志与异常信息中是否也泄露了凭证

## 产出要求

交付：泄露清单（含位置与历史提交）+ 轮换记录 + 防护措施（钩子/扫描集成）。
