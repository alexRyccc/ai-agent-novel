# 异常处理规范

## 目标

产出异常分类明确、信息可诊断、不吞异常的处理链路。

## 适用场景

- 异常处理混乱
- 错误信息不可诊断
- 统一异常出口

## 工作流

1. 区分三类异常：业务异常（可预期）、校验异常、系统异常（不可预期）。
2. 自定义业务异常携带错误码，禁止用异常消息做流程判断。
3. 全局 `@RestControllerAdvice` 统一转响应，映射到正确 HTTP 状态码。
4. 捕获后必须处理：要么恢复、要么补充上下文后重抛、要么记录并降级。
5. 禁止 `catch (Exception e) {}` 空捕获；禁止只打印不处理。

## 检查清单

- [ ] 是否有吞异常的空 catch
- [ ] 异常堆栈是否被丢弃（`new XException(msg)` 未传 cause）
- [ ] 错误信息是否包含敏感数据（密码、token、身份证）
- [ ] 是否区分了可重试与不可重试错误

## 产出要求

交付：异常类层级 + 全局处理器 + 错误码表 + 典型场景示例。
