# 排版系统

## 目标

产出层级清晰、阅读舒适的排版规范。

## 适用场景

- 文字层级混乱
- 长文阅读体验差
- 中英文混排错位

## 工作流

1. 字号取模数比例（1.2~1.25），层级控制在 5~6 档，过多则失去区分度。
2. 行高与字号反比：正文 1.5~1.7，标题 1.2~1.3。
3. 正文行宽控制在 45~75 字符（`max-width: 65ch` 左右）。
4. 中文优先用系统字体栈（PingFang SC / Microsoft YaHei），避免加载大字体文件。
5. 字重用于强调层级，正文 400、次级标题 600，避免大面积 bold。
6. 数字与代码用等宽字体，保证对齐。

## 检查清单

- [ ] 标题层级是否跳级（h1 → h3）
- [ ] 正文行高是否过窄导致拥挤
- [ ] 长文本是否有最大行宽限制
- [ ] 中英文混排是否有合理间距
- [ ] 字体是否会在内网/离线环境加载失败

## 产出要求

交付：排版令牌（字号/行高/字重）+ 使用规范 + 典型页面示例。
