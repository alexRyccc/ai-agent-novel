# 开源许可证合规

## 目标

产出许可证清单与风险分级，明确可商用边界。

## 适用场景

- 开源合规审查
- 对外交付前检查
- 引入新依赖评估

## 工作流

1. 枚举所有直接与传递依赖及其许可证。
2. 按风险分级：MIT/Apache-2.0（低）、LGPL（中，动态链接）、GPL/AGPL（高，传染）。
3. 检查是否有代码片段从网上复制（含许可证不明来源）。
4. 对高风险依赖评估：替换、隔离部署、或获取商业授权。
5. 输出合规清单供法务/交付评审。

## 检查清单

- [ ] 是否只查了直接依赖
- [ ] 是否处理了双许可证（可择一）的情况
- [ ] AGPL 是否被用于对外提供的网络服务
- [ ] 是否保留了必要的版权声明与 NOTICE 文件

## 产出要求

交付：许可证清单 + 风险分级 + 处置建议 + 声明文件。
