# SAST 安全扫描

## 目标

识别并修复代码层安全缺陷，给出可验证的修复与回归用例。

## 适用场景

- 上线前安全评审
- 安全漏洞整改
- 引入 SAST 工具

## 工作流

1. 明确覆盖范围：SQL 注入、XSS、SSRF、路径穿越、反序列化、越权。
2. 跑 SAST 工具并人工复核高危项（工具误报率高，不能照单全收）。
3. 对每个确认问题给出：触发路径 → 影响 → 修复方式 → 回归验证方法。
4. 修复优先用参数化/白名单/最小权限，而非过滤黑名单。
5. 补充安全回归测试用例，防止回退。

## 检查清单

- [ ] 拼接 SQL 是否全部参数化
- [ ] 用户输入是否都做了校验与转义
- [ ] 文件路径操作是否限制在白名单目录内
- [ ] 是否使用了不安全的反序列化（`ObjectInputStream`、fastjson autotype）
- [ ] 接口是否校验了资源归属（越权）

## 产出要求

交付：漏洞清单（含等级）+ 逐项修复 diff + 回归用例 + 复扫结果。
