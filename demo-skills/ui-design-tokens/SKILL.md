# 设计令牌体系（Design Tokens）

## 目标

建立分层令牌（原始值 → 语义 → 组件），使视觉决策集中可维护。

## 适用场景

- 新建或重构样式体系
- 需要支持多主题
- 视觉不一致难以收敛

## 工作流

1. 三层结构：`--raw-*`（色值/数值原始值）、`--color-*` 等语义层、`--btn-*` 组件层。
2. 语义层只引用原始层，组件层只引用语义层，禁止跨层跳跃与硬编码色值。
3. 间距用统一比例尺（4/8 基准：4、8、12、16、24、32、48、64）。
4. 字号用模数比例（如 1.25 倍：12、14、16、20、25、31），行高随之递增。
5. 圆角、阴影、层级（z-index）同样令牌化，避免散落魔数。
6. 主题切换只需覆写语义层，组件层零改动。

## 检查清单

- [ ] 是否存在硬编码色值（`#fff`、`rgb(...)`）绕过令牌
- [ ] 间距是否都落在比例尺上（有无 13px、7px 这类随手值）
- [ ] z-index 是否集中管理（禁止 9999 满天飞）
- [ ] 语义命名是否表达用途而非外观（`--color-danger` 优于 `--color-red`）
- [ ] 令牌命名是否可被团队一致理解

## 产出要求

交付：令牌清单（三层结构）+ 使用规范 + 迁移对照表（旧值 → 新令牌）。
