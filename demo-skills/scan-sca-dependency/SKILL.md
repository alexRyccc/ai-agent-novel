# 依赖漏洞扫描（SCA）

## 目标

产出可直接执行的依赖升级/替换清单，并评估升级影响。

## 适用场景

- 供应链安全审查
- CVE 应急响应
- 依赖治理

## 工作流

1. 导出完整依赖树（含传递依赖），不要只看直接依赖。
2. 用 SCA 工具比对 CVE 库，按 CVSS 分数与可利用性排序。
3. 对每个高危依赖评估：能否升级、升级的破坏性、能否排除、能否替换。
4. 优先升级到同大版本的最新补丁版，减少兼容风险。
5. 升级后跑全量测试 + 回归验证。

## 检查清单

- [ ] 是否只看直接依赖忽略了传递依赖
- [ ] 是否存在无法升级的死依赖（需评估隔离或替换）
- [ ] 许可证是否合规（GPL 传染性风险）
- [ ] 是否锁定了可复现的版本

## 产出要求

交付：漏洞清单（含 CVSS）+ 处理方案表 + 升级后测试结果。
