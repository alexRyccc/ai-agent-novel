# 色彩系统与对比度

## 目标

产出语义清晰、对比达标、可扩展的色彩体系。

## 适用场景

- 建立品牌色板
- 对比度不达标
- 语义色混乱

## 工作流

1. 分三层：原始色阶（50~900）、语义色（primary/success/warning/danger/neutral）、组件色。
2. 语义色命名表达用途（`--color-danger`），不表达色相（`--color-red`）。
3. 每个语义色配套：默认、hover、active、subtle（浅底）、on-（其上文字色）。
4. 所有前景/背景组合必须实测对比度：正文 ≥4.5:1，大字与图形 ≥3:1。
5. 状态不能只靠颜色区分（配合图标或文字），兼顾色觉障碍。
6. 深浅两套主题共享语义层，只切换原始色阶映射。

## 检查清单

- [ ] 是否有硬编码色值绕过色板
- [ ] 所有文字/背景组合是否实测过对比度
- [ ] 危险/成功等状态是否只靠颜色表达
- [ ] 深色主题下色板是否重新校验过对比
- [ ] 是否有色彩无障碍（色盲）友好性检查

## 产出要求

交付：色板表（含色值）+ 对比度实测矩阵 + 语义映射表 + 使用规范。
