## 正文

你好，

给你推荐一个我们团队内部做的小工具 **SkillForge**，一个「本地技能管家」。它解决的问题很具体：内网的 AI 助手（Metis）没法自动调用团队积累的开发规范——这些规范散在文档、Wiki、老同事脑子里，AI 既看不到也用不上。SkillForge 把这些规范整理成一份份「技能」（`SKILL.md`），然后负责三件事：

1. **收进来**：一条命令把散落的技能规范扫描入库；
2. **调对**：AI 接到任务时，自动选出最对口的那个技能并照着做；
3. **看得见**：用「真实采纳率」衡量每个技能到底好不好用，没人用的技能自然浮出来；而且每次推荐都会解释「为什么推它、我该不该信」。

**装起来只有一条命令**（前提：机器上有 Python 3.11 或更高版本，不需要联网、不需要装任何第三方包）：

```
python sfx.pyz serve
```

浏览器打开 **http://127.0.0.1:7788**，就是一个本地看板：左边技能列表、中间能试玩匹配、右边是统计。没有服务器、没有账号，所有数据都留在自己机器上，断网也能用。

**试用三步**（附件里 `交付说明.md` 写得更详细）：

1. 扫描示例技能：`python sfx.pyz scan --roots demo-skills`
2. 试匹配：`python sfx.pyz match "帮我写一个 Spring Boot REST 接口"`
3. 真的用某个技能干成了活，就投一票：`python sfx.pyz load java-spring-boot-api`

几点说明：

- **内网可用**：整个工具只在本地跑，不连外网，页面零 CDN。
- **数据只在本机**：Windows 落在 `%LOCALAPPDATA%\sfx`，不经过任何服务器。
- **默认只服务本机**：看板只监听 127.0.0.1，别人访问不到，这是刻意的安全设计。
- **当前是单机版**：适合个人/小范围验证；团队账号、审核流程等是下一阶段的事。

附件是一个 zip 包（375 KB），里面除了 `sfx.pyz` 单文件，还有 30 个示例技能、一份完整的项目说明、`交付说明.md` 和 `README.md`。如果贵司邮箱网关把 `.pyz` 当可疑压缩包拦截了，把 zip 里的内容解压后，用 `python -m sfx serve` 一样能跑（README 里写了目录形态的用法）。
